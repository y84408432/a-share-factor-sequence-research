# 研究设计与实验协议

## 1. 任务定义

研究对象为历史沪深300成分股。股票 i 在交易日 t 收盘后产生预测，标签为

\[
y_{i,t}=\frac{O_{i,t+6}}{O_{i,t+1}}-1.
\]

O 为 Qlib 复权开盘价。信号时点与目标起点之间不共享未来输入。研究评估截面收益排序；该收益定义仅用于理论评价，不意味着能够按该价格真实成交。

## 2. 特征表示

- **基础量价（8项）**：日收盘收益、隔夜开盘缺口、日内收益、日内振幅、上影线、下影线、VWAP偏离和相邻日成交量变化率。由逐日 OHLCV 构造。
- **滚动金融因子（16项）**：`RET1, ROC5, ROC20, RANK20, SUMD20, RVOL20, STD20, RSQR20, VMA10, VSUMD20, VSTD20, CORD20, KMID, KLEN, KSFT2, VWAP0`。精确表达式以 `lstm_research/feature_spec.py` 和 `07_compare_representations.py` 为准。滚动因子并非独立的16个市场信号，其部分窗口和统计量存在重叠。

训练期内拟合缩放和截尾参数，验证与后续评价期不重新拟合。严格窗口样本保持非缺失/有限，并对照相同股票—日期键。个别实验对输入窗口、信息集及参数量的差异在比较时明确报告。

## 3. 时间与研究角色

| 时段 | 用途 |
|---|---|
| 2015年 | 指标与序列构建的历史预热 |
| 2016—2020 | 模型训练与缩放器拟合 |
| 2021—2022 | 假设检验、模型选择与受控探索 |
| 2023—2024 | 冻结模型的跨时期评价 |
| 2025—2026（2026部分年度） | 最终冻结模型评价 |

训练/评价边界使用标签结束日约束，输入序列可包含预测时点之前的历史交易日。2025—2026最终期有436个有效信号交易日，最后信号日期2026-10-23（行情截止2026-11-02，需要后续第6交易日开盘作为标签终点）。

## 4. 实验链条

| 阶段 | 实验内容 | 作用 |
|---|---|---|
| V1–V2 | Qlib因子面板、严格窗口、标签及训练期预处理 | 数据质量与信息边界 |
| V3 | Ridge、MLP、LightGBM、LSTM首轮比较 | 参考模型与假设生成 |
| V4–V5 | 历史窗口和模型容量/随机种子对照 | 滚动因子多期信息的边际效果 |
| V6 | 仅评价时扰动、训练和评价均扰动 | 区分模型顺序敏感性与一致扰动适应能力 |
| V7 | 基础量价 vs 滚动因子，1/30日受控比较 | 特征表达与历史长度交互 |
| V8 | 基础量价历史顺序扰动及同信息集 Ridge/MLP | 历史排列与模型结构比较 |
| V9 | 四组固定模型2023—2024年评价 | 泛化稳定性 |
| V10 | 五分组收益、五日错峰持有、成本情景 | 理论经济价值 |
| V11 | 历史成分、未来标签筛选与执行限制 | 数据有效性 |
| V12 | 四组固定模型2025—2026年最终评价 | 一次性最终结果 |

V9/V12固定模型为单期滚动因子 Ridge、30日基础量价 Ridge、30日基础量价 LSTM 与30日滚动因子 LSTM。LSTM报告三个预设随机种子结果，评价期不重新训练。

## 5. 统计量与解释

主要指标为每个评价日股票截面 `Spearman(pred, actual)` 的日期等权平均。配对差异通过相同交易日 RankIC 的差值及 Newey–West/HAC (lag=10) 估计不确定性。随机种子与五个错峰持有批次共享市场观测，不作为独立交易日。

V7–V8在探索验证期完成，因此与其相关的HAC区间并未校正整个研究链条的多重检验。V8顺序扰动证据说明正确时间排列对**当前LSTM配置**的影响；它本身不构成循环模型优于所有非循环算法的结构性因果证明。

详细结果与图表参阅 [`Research_Report.pdf`](Research_Report.pdf)。
