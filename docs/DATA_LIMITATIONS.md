# 数据有效性与经济价值解释范围

## 历史成分股

V11验证2023—2024年冻结预测样本与本地 `csi300.txt` 成分生效区间机械一致，活跃成分股数量在每个有效日期为300。该文件与Qlib接口来自同一本地数据源，历史公告公布时点(PIT)尚未由独立来源认证。源文件另含7条2005—2007年非标准标识 `SHT00018`，未进入当前训练或评价时期。

## 标签可用性

预测目标 `Open(t+6)/Open(t+1)-1` 需要未来两次开盘价。2023—2024年事前候选141,462条中有47条因标签不可用排除；最终期也有128条被排除。筛选条件由未来信息决定，因而理论评价只覆盖满足完整标签的样本，可能存在可观测性选择偏差。独立还原完整原始股票/行情不可用性需更详细源数据。

## 开盘成交与复权

Qlib复权开盘价支持标签和理论收益构建，但不等于真实交易所集合竞价成交价或成交能力。V10/V12只核对开盘价字段、量价一致性和大幅跳空等风险代理指标。涨跌停封单、ST及暂停交易状态、最小交易单位、市场冲击、价格滑点和当期税费未被独立全面模拟。

## 经济收益定义

研究中将每日预测截面分五组，报告Q5、Q1、Q5−Q1以及Q5相对股票池的未来5日理论收益。五日错峰方案以五个起始相位分别模拟，报告相位统计而不将相位视为五份独立样本。0/5/10/20bp单边摩擦是情景敏感性假设，非历史实际成交费用认证。Q5−Q1是统计收益差，不代表可立即实施真实做空。

## 统计推断

RankIC按日计算、日期等权聚合；配对HAC区间将市场日期作为分析单位。2021—2022年的检验经过多轮研究探索，不应被表述为全流程经多重比较控制的确认性发现。2025—2026年最终评价沿用冻结模型，其中2026年为非完整自然年度。
